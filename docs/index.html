Source: Georgia Power's own outage map (built on KUBRA's Storm Center product). Covers Georgia Power's service territory — the majority of the state's population, though electric cooperatives and municipal utilities aren't included. Weather from Open-Meteo, alerts from the National Weather Service, county from the FCC's Census Area API — all captured once, when each outage was first seen.

This page only shows active outages and the last 48 hours for speed. The full history, going back to when this tracker started, lives permanently in the data/ folder of this repository — one file per day, downloadable directly from GitHub, no tools required. That's your benchmark dataset.
